# Ighodalo SFP

Swing Failure Pattern EA (`SFP_EA.mq5`) with ATR risk, breakeven, and
reversal exit - a separate implementation from `../Belema-SFP/` and `../SFP/`
(different author/codebase, same general SFP concept).

| File | What changed |
|---|---|
| `Ighodalo SFP.mq5` | Uses a MACD filter for confirmation. |
| `Ighodalo SFP V8.mq5` | Swaps the MACD filter for BB Trend & MA Ribbon filters instead, and adds session filtering plus configurable support/resistance count. |
