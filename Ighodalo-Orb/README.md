# Ighodalo Orb

Open Range Breakout (ORB) EA with customizable session times and power-candle
confirmation, built on Belema's ORB expert advisor.

| File | What changed |
|---|---|
| `Ighodalo Orb.mq5` | Base (~917 lines): retains trade-management features from the SFP EA, including hedging and FVG confirmation. |
| `Ighodalo Orb V2.mq5` | ~879 lines: switches to using the SFP EA's position sizing and extends the ORB box to the end of the current day. |
| `Ighodalo Orb v3.mq5` | ~892 lines, ~27 lines different from V2 - a small refinement on V2, not a duplicate. |
