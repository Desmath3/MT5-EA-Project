# Ighodalo Gold BnR - Kenton Royal

Same breakout-and-retest strategy as `../Ighodalo-Gold-BnR/`, but this build
has a hard-coded expiration check (2025-08-17 23:59:59 GMT) in `OnInit` that
disables trading and prints a message to contact
`@ighodaloxauusd@gmail.com` / `@__ighodalo` on X to renew. This reads as a
time-limited copy distributed to a specific recipient ("Kenton Royal") rather
than a strategy iteration - kept in its own folder rather than merged with
the base `Ighodalo-Gold-BnR` version for that reason.
