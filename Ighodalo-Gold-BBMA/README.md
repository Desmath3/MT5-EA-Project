# Ighodalo Gold BBMA

An ATR-risk EA with dual-level breakeven/reward and a MACD + Bollinger Band
reversal trigger, plus a floating-profit close-all feature
(`MACD_BB_ReversalEA.mq5`). Only one version exists in this repo.

Closely related to `../MACDBB/` (same strategy description, same header),
but confirmed via diff to be genuinely different code - an independent
implementation of the same idea, not a version of it.
