# RSI Martingale

RSI-based entry with Martingale position sizing (`RSI_MartingaleEA.mq5`):
RSI signals with initial lot size / lot multiplier Martingale sizing.

Only one version exists in this repo. A `RSI Martingale v2.mq5` file
previously lived here, but it wasn't actually RSI code - its header read
`ZeiRangeADX.mq5` (same Zeiierman origin as `../Consolidation-Range-ADX/`)
and the body was a 59-line empty indicator stub with a literal
`// TODO: calculation logic` placeholder. It's been removed as a stray
misfiled template rather than real content.
