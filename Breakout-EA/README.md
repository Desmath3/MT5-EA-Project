# Breakout EA

A breakout EA with ATR-based risk, BB Trend and MA Ribbon filters, session
filtering, pivot detection, and configurable support/resistance count.

| File | What changed |
|---|---|
| `Breakout EA.mq5` | Base (`Breakout_EA.mq5`): advanced trade management - partial close, breakeven, reversal exit. |
| `Breakout EA v2.mq5` | Adds a dual-level breakeven trigger and reward on top of the base. |
