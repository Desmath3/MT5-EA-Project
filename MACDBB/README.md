# MACDBB

An ATR-risk EA with dual-level breakeven/reward, MACD + Bollinger Band
reversal trigger, and a floating-profit close-all feature
(`MACD_BB_ReversalEA.mq5`). Only one version exists in this repo.

Closely related to `../Ighodalo-Gold-BBMA/` (same strategy description, same
header), but confirmed via diff to be genuinely different code (304 vs 321
lines, 52 lines of real differences) - not merged since they're independent
implementations of the same idea rather than one being a version of the other.
